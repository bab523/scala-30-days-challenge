# Day 1 — Scala Essentials

## Tasks
- Create programs using val, var, lazy val and immutable collections.
- Write for-comprehensions using yield for students and marks.
- Compare List, Vector, Set and Map with simple examples.
- Create a trait Logger and implement it in two classes.
- Scenario: Build a small student-grade processor using only Scala collections.

## What I learned
- `val` is immutable, `var` is mutable, `lazy val` is evaluated only when first accessed.
- `for-yield` builds a new collection from an existing one.
- List (ordered, allows duplicates), Vector (fast indexed access), Set (no duplicates), Map (key-value pairs).
- Traits can be implemented differently by multiple classes (polymorphism).

## How to run
```bash
scala Main.scala
```
